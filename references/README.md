# 参考资料与依据

这里用于组织各章引用的资料、关键主张的依据和核查记录。项目初始化阶段尚未建立完整的技术参考文献库；下表是记录规范，不表示已有完整研究综述。

## 建议记录的字段

| 字段 | 内容 |
| --- | --- |
| reference_id | 稳定标识，用于章内引用 |
| title / author / date | 资料名称、作者或发布机构、发布时间 |
| url / identifier | 可访问地址、DOI 或其他稳定标识 |
| accessed_at | 最近实际核查日期 |
| supports | 支持的具体主张及章节位置 |
| locator | 页码、章节、图表号或原文定位 |
| evidence_type | 官方文档、论文、标准、实测记录或其他类型 |
| limitations | 适用范围、局限、不同意见和时效条件 |
| reuse_terms | 如复用内容，记录适用许可或使用依据 |

优先引用一手来源，区分来源直接支持的结论与作者推断。不要把搜索摘要当成已经阅读和核查的全文，不提交无法核实的生成文献。

许可设计的背景资料集中在[使用说明](../docs/USAGE.md)中。后续技术参考资料按章节整理，避免重复复制原作品全文。
