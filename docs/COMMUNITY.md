# 社区与讨论

更新日期：2026-10-24

本项目欢迎全球 AI 爱好者和从业者共同讨论。中文、英文均可；长篇提案可以补充另一种语言的简要说明，以方便协作。

不会编程也可以参与。提问、纠错、提出反例、补充参考资料、分享成功或失败经验，以及改善文字和翻译，都是有价值的贡献。首次参与可以阅读[置顶欢迎帖](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/discussions/1)。

## 讨论放在哪里

| 内容 | 入口 |
| --- | --- |
| 定义、原则、目录与方法讨论 | [GitHub Discussions](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/discussions) |
| 明确的事实错误、失效链接、可执行修改 | [GitHub Issues](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/issues) |
| 可供合并的文字、模板或案例改进 | Pull Request，先阅读[贡献规则](../CONTRIBUTING.md) |
| 完整材料与版本 | [项目首页](../README.md) |

GitHub Discussions 是当前项目内的讨论入口。Telegram、Discord、微信公众号及其他外部渠道尚未指定；确认真实账号后会在这里登记。不要把非官方链接当作项目授权或背书。

明确错误和可执行修改继续进入 Issues；可直接合并的内容通过 Pull Request 提交。

## 怎样发起一条有用的讨论

说明问题所处的环节、实际任务、已有数据组织方式和遇到的失败。讨论方法时给出适用条件、反例或公开依据；报告效果时说明比较基线、环境与验证过程。

欢迎纠正作者观点。讨论聚焦论据与方法，尊重不同经验，不攻击个人，不发布广告或无关推广。未公开或无权分享的资料，请用可公开的概述或虚构示例替代。

## 从讨论到书稿

讨论中的建议不自动成为审定结论。收入书稿前，需要核对事实、取得适用的贡献授权、记录来源与署名，再由维护者审阅合并。未验证的观点明确保留其状态。

额外使用授权的申请方式见[使用说明](USAGE.md)。Issue 和 Discussion 通常公开，请勿直接提交合同、联系方式、商业秘密或敏感材料。

## English

Use Discussions for questions and proposals, Issues for actionable corrections, and pull requests for changes intended for inclusion. Chinese and English are welcome. Explain the task, evidence, baseline and limitations. Treat people respectfully, and keep private or unauthorized material out of public threads.

No coding experience is required. Start with the pinned welcome discussion. Use **Announcements** for maintainer updates, **Questions** for questions, **Proposals** for framework and manuscript improvements, and **Practice** for cases and replications.

Discussion does not automatically make a proposal an accepted conclusion or grant permission to incorporate every contribution. Follow the contribution terms before inclusion. External chat and media accounts will be listed only after the maintainer designates them.
