# 示例模板

状态：初始化示例，供学习与共创，不是通用标准或已经验证的最优方案。

模板内的 `kind`、`status` 等字段描述业务记录，取值与[写作指南](../docs/WRITING_GUIDE.md)中的文档编辑元数据各自独立。例如，`status: proposed` 表示业务决定尚待确认，并非文稿的编辑进度。需要同时保存两种元数据时，使用 `document` 和 `record` 命名空间区分，或将业务记录放入正文代码块。

| 模板 | 用途 |
| --- | --- |
| [记忆条目](memory-entry.md) | 记录一项有明确来源、范围和状态的长期信息 |
| [决策记录](decision-record.md) | 保留决定、理由、适用范围和替代关系 |
| [上下文清单](context-pack.md) | 为当前任务选择资料、说明优先级和待确认事项 |

按任务删减字段，不需要为了填表而填表。时间、状态、标识符和来源应由实际系统验证；访问控制与指令优先级不能只靠文档中的一段文字实现。复制模板时保留适用许可和来源，实际使用范围见[使用说明](../docs/USAGE.md)。

配套演示：[新旧项目决定的记忆维护](../examples/memory-update/README.md)。
