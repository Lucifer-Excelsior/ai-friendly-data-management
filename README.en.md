# AI-Friendly Data Management

**Principles, methods and practices across the lifecycle of training, inference and AI agents**

[中文](README.md) · [Book outline](book/README.md) · [Contribute](CONTRIBUTING.md) · [Discussions](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/discussions) · [License](LICENSE.md)

> **v0.1.0 — project initialization.** This repository currently contains a proposed six-part, 24-chapter outline, editorial guidance, a serialization plan and illustrative templates. The book and manifesto are being developed. The outline has not been finalized, and the examples are not evidence of measured performance improvements.

## Purpose

How should data be organized, described, supplied, updated and retired so that AI can understand tasks and perform useful work more reliably, with appropriate costs and maintenance effort?

This publicly developed book welcomes AI enthusiasts, practitioners, data professionals and researchers worldwide. It considers both data consumed by AI and data produced for subsequent use: training examples, knowledge units, context, tool observations, task state, memory and feedback.

## Proposed scope

1. Definitions, principles and a lifecycle reference framework.
2. Data acquisition, organization and governance.
3. Data for training, adaptation and evaluation.
4. Retrieval, inference and context management.
5. Agents and layered memory.
6. Continuous improvement, retirement and implementation.

See the [full proposed outline](book/README.md). Chapters are currently planned, not completed. Applications using an existing model do not have to include a training stage. Quality, provenance, permissions, versioning, responsibility and cost should be considered across the chosen activities.

## Collaboration and publication

GitHub hosts the complete evolving manuscript, examples, templates, sources and revision history. Articles published through designated media will provide a complete method or example and link back to the relevant material.

Use [Issues](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/issues) for actionable corrections and [Discussions](https://github.com/Lucifer-Excelsior/ai-friendly-data-management/discussions) for questions, counterexamples and proposals. Chinese and English are both welcome. Read the [contribution terms](CONTRIBUTING.md) before submitting material for inclusion. No external chat server or media account has yet been designated.
