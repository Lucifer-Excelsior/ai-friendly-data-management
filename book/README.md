# 全书目录与写作范围

> 状态：初始目录建议，待主编审定。六篇二十四章均为规划；下表中的问题和预期交付描述写作目标，不表示章节正文、案例或工具已经完成。

本书围绕一个问题展开：怎样组织、提供和维护数据，才能让 AI 在具体任务中获得更好的效果、更高的效率和更合理的成本？

目录同时考虑模型研发者、AI 应用开发者、数据管理人员和日常使用者。各章从任务出发，说明数据的组织方式、使用过程、维护责任及验证方法。训练与适配属于可选路径；采用现有模型的应用，也可以沿检索、推理、智能体和记忆等章节形成完整的实践路线。

## 阅读与参与

- 想了解全貌：从第一篇开始，再按实际任务选择其他篇章。
- 想改善知识问答与资料处理：重点关注第二篇、第四篇，并参考第 04、21、22 章。
- 想建设长期运行的智能体：重点关注第四篇、第五篇和第六篇。
- 想准备训练或评测数据：重点关注第二篇、第三篇，并参考第 04、22、23 章。
